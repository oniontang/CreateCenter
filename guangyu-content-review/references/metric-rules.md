# 内容数据口径

## 保留原始信息

| 字段 | 记录方式 |
| --- | --- |
| 作品 | 平台、作品ID/链接、发布版本、时长/形式 |
| 时间 | 发布时刻、采样时刻、统计覆盖时长；注明时区 |
| 流量 | 平台实际字段及单位，区分曝光、播放、有效播放、观看人数 |
| 留存 | 平台实际提供的起播、留存曲线、完播或平均观看，不自行推导缺项 |
| 互动 | 点赞、收藏、分享、评论、关注等动作数，保留可得口径 |
| 转化 | 用户关心的咨询、试用、报名或购买，写清归因来源和统计范围 |
| 反馈 | 有位置的评论/私信摘录；公开展示时匿名化 |

没有提供的字段写“未提供/不可得”，不当成0。只有稿子没有发布反馈时，不输出实际流量结论。

## 计算与比较

- 仅在平台定义与分母明确时计算率；写出公式和数据来源。
- “点赞数/播放次数”是每次播放对应的点赞动作比，不等于独立观众中点赞者比例。
- 完播率优先使用平台明确给出的定义，不拿平均观看时长/总时长冒充完播率。
- 不混用不同账号、时长、平台、流量来源或采样窗口的数据来证明一个修改有效。
- 用户要对比时先检查可比性；只能有限比较就写明限制。样本少时优先描述差异，不给统计显著性或确定因果。
- 平台指标和规则需要外部核验时使用当前一手来源，不假定各平台算法相同，不编造流量池门槛。

## 结论表述

可写：“这条内容的收藏动作占播放量的比例更高，样本与时间窗见表。评论中有人明确提到操作清单，但尚不能证明提升只由清单带来。”

不可写：“用了这个开头，所以系统给了二级流量池”“收藏率到某个固定值就一定爆”“没有评论说明所有人都不感兴趣”。

有真实对照和条件说明才讨论因果证据。选择下一次实验时，尽量控制一个可操作变量，不把观察性比较包装成随机试验。
