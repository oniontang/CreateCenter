# guangyu-grill

围绕计划或设计逐题深入访谈，直到厘清关键决定与依赖关系。用于压力测试计划、查找设计漏洞和整理想法。

## 安装与使用

把整个 `guangyu-grill` 文件夹复制到当前 Agent 的技能目录，并确认已识别。例如Codex通常使用 `~/.codex/skills/guangyu-grill/`，Claude Code通常使用 `~/.claude/skills/guangyu-grill/`；具体以当前应用配置为准。

通过 `$guangyu-grill` 或“Guangyu grill，帮我逐个问清楚这个计划”触发。是否支持斜杠命令由宿主决定，不假设存在自动调度总入口。

来源与许可见根目录的《来源与许可》。
